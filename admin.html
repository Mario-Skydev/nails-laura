¿Cómo consigo la clave?
  1. En GitHub, abre tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca el repositorio de tu página.
  3. En Permissions → Contents elige Read and write.
  4. Crea el token, cópialo y pégalo aquí.
